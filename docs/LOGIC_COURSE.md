# Logic and Critical Thinking — OpenForge Academy Course (2026)

**Author and textbook source:** Mabrig Korie, *Logic and Critical Thinking: A Complete Open-University Textbook*, First Teaching Edition (2026). The author-supplied manuscript is a 60-page DOCX with 23 instructional chapters, 4 parts, appendices A–F, a programme framework, LCT 201 12-week syllabus and references.

## Deliverables and rights

The interactive **OpenForge application** adds a browsable course track with 23 source-aligned lesson reviews, 23 formative self-check questions, local reading + quiz completion, Text Reader handoff, Visual Learning Studio handoff, and optional saving to the existing offline study-circle Tutor. It does **not** contain the complete copyrighted textbook text. The course's 23 original full-length chapters and appendix content are separately packaged as an offline standalone HTML study edition and structured JSON course kit for the author; these are intentionally not committed to this **public** GitHub repository without a separate publishing/license decision.

The HTML kit is a **complete chapter-content course**; the in-app catalogue is a companion 23-chapter review track. Do not market the in-app review summaries alone as the complete copyrighted textbook.

## Four instructional parts

| Part | Chapters | Scope |
|---|---|---|
| I. Foundations of Critical Thinking | 1–7 | CLEAR routine; arguments and reconstruction; induction, deduction, abduction; fallacies; biases; evidence; mapping |
| II. Formal Logic | 8–15 | Symbolization; conditionals; truth tables; validity and soundness; proofs; decision rules; quantifiers; countermodels |
| III. Applied Critical Reasoning | 16–19 | Science; law, policy and ethics; media / AI literacy; risk and statistics |
| IV. Advanced Argumentation | 20–23 | Dialogue and rhetoric; logic and computing; research critique; applied capstone |

The supplied teaching edition proposes **18 core credits** and up to **six elective credits**. These are not approved credits, a degree, or a certificate recognized by an awarding body. The app issues **no academic credentials**; its completion badge is only a personal on-device practice marker.

## Demonstration script (one browser session; no AI tokens)

1. Open Home → **Logic and Critical Thinking — 23-Lesson Course**.
2. See progress **0 / 23**. Expand all 23 lessons to confirm four separate parts and Chapter 23 capstone.
3. Read Chapter 1: the CLEAR routine. The app presents its teaching review, worked example and source label.
4. Select **Answer 2: Clarify, assess evidence, and consider alternatives** and press **Check my answer**. It records a successful local formative practice check.
5. Press **Mark lesson as read**. Progress becomes **1 / 23 complete** (requires *both* passed quiz and read check).
6. Reload. The local milestone persists; no email, login, cloud sync or analytics are used.
7. Press **Make infographic or video from lesson**. The Visual Studio is prefilled with Chapter 1 teaching text; choose flowchart, create SVG, captions, and browser video.
8. Return and press **Save lesson to offline study circle & open Tutor**. A clearly labelled course **review note** is created locally, and the existing Offline Tutor can retrieve it. The cloud AI tutor still requires explicit owner configuration and student consent.

Browser CI checks these working journeys using synthetic/local content; this is not a human verified physical-device review.

## Standalone course kit (delivered privately to author)

The offline HTML study edition includes the **entire original teaching text** for 23 chapters, course navigation/search, 23 formative answer checks, a CLEAR guided demonstration, local progress, browser speech synthesis, concept maps, and a non-accredited private completion record. The JSON companion preserves book chapters, text tables and appendices for future LMS packaging.

The published GitHub application does not automatically have access to files attached in a private ChatGPT conversation. To make the **full** textbook available from the live app, the rights holder must explicitly choose permitted distribution terms and upload the generated full course asset through a planned import / protected storage flow. Do **not** silently expose the manuscript at a public static URL.
